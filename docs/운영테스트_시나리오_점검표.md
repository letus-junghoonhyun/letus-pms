# LETUS PMS 실제 운영 테스트 시나리오 · 점검표

- 작성: 2026-11-08 · 대상: https://letus-pms.vercel.app
- 목적: 전체 배포 전, 실제 업무 흐름대로 돌려 보고 **EDI 재고 = PMS 재고**가 유지되는지 확인
- 원칙
  - 테스트는 실제 EDI에 반영되는 건이므로 **소량(1~2장)·실제로 일어난 이동**으로만 한다. 필요하면 바로 반대 건으로 되돌린다.
  - 각 항목은 ☐ 통과 / ✕ 실패 / – 해당없음 으로 표시하고, 실패는 화면 캡처와 함께 "이슈 기록"에 적는다.
  - 마지막에 EDI 재고 화면과 PMS 재고 화면 숫자가 같은지 반드시 확인한다.
