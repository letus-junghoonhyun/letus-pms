## 1. 한 줄 요약

파렛트 월마감은 **AJ에서 빌린 파렛트 비용을 쓴 곳별로 나눠서 관계사(퍼시스·일룸·시디즈)와 협력업체에 청구하는 작업**이에요.
- 들어오는 돈(관계사 청구): 월 약 **1억 4,760만 원**(8월, 공급가)
- 나가는 돈(AJ 임차료): 월 약 **9,900만 원**(8월, 공급가)
- 차액 월 약 **4,800만 원**이 운송사업팀(퍼시스양지경인운송 코스트센터) 용역수입

## 2. 마감 기간과 흐름

- **기간**: 전월 26일 ~ 당월 25일(AJ 거래명세서 사용기간과 같음). 한 달 일수(28~31일)를 매번 바꿔야 함.
- **용어**
  - **구내용** = 그 기간 매일 재고의 합(파렛트·일). 예) 양지물류센터 8월 345,204
  - **월평균(일평균 사용량)** = 구내용 ÷ 일수, **올림**. 예) 345,204 ÷ 31 = 11,136장
  - 청구액 = 월평균 × 단가

```
[AJ] 거래명세서 (작업장별 시트 ~400개, 매일 재고 → 구내용)
      │
      ▼ ① 구내용 계산기 : 작업장별 구내용 → 월마감 파일 순서로 정렬, PDF 총계와 대조
[월마감 파일] AJ자료입력 (작업장 ~460행 = 바로스 센터·시공팀 / 퍼시스 공장 / 일룸 상품 협력사 / 시디즈 공장·협력사 / 11A / 23E)
      │
      ▼ ② ERP 제품구분별 수주/판매실적 (퍼시스·일룸·시디즈 매출: 경인내수 / 지방내수 / 해외)
      ▼ ③ ERP 시디즈 음성창고 재고금액 → 양지센터 시디즈 몫 파렛트 = 재고금액 ÷ 881,485
      ▼ ④ EDI 11A 출고내역 → 일룸 : 시디즈 출고 비율
[요약및변환] 사용처별 월평균을 브랜드 × 내수/해외로 안분 (INT 버림 + 보정 1장)
      │
      ▼
[★출력★] 브랜드별 내수/해외 수량·금액 + 전월 대비 → 담당자 이메일
[☆청구☆] ERP 전표 줄 (외상매출금 / 예수부가세 / 용역수입) + 협력업체 미수금 + AJ 임차료
```

## 6. 검토에서 찾은 문제

### 6-1. 수식 오류 (실제 금액 차이)
`AJ자료입력` 시트의 소계 수식이 구내용(F)·월평균(G)·금액(I) 열마다 범위가 달라요.

| 행 | 구내용(F) | 월평균(G) | 금액(I) |
|---|---|---|---|
| 156 | F151:F154 | **G150**:G154 | I151:I154 |
| 170 | F160:F169 | **G159**:G169 | **I157**:I169 |
| 174 | F171:F172 | G171:G172 | I171:**I173** |
| 292·310 | …:F291 / F308 | 같음 | **I290 / I307**(한 줄 빠짐) |
| 333 (바로스 합계) | F150·F159 포함 | G174 포함 | I174 포함 — 셋이 다름 |
| 355 (안성공장) | F334:**F353** | G334:**G352** | I334:**I352** |
| 366 (충주1) | F356:**F365** | G356:**G364** | I356:**I364** |
| 438 (일룸 합계) | F372:**F436** | G372:**G435** | I372:**I435** |

8월 실제 영향(줄별 합 vs 소계):
- 퍼시스 블록: 월평균 **3,043 → 소계 3,012 (31장 누락)**, 금액 7,607,500 → 7,530,000 (**77,500원 누락**)
- 바로스 블록: 금액 123,177,500 → 123,165,000 (12,500원 누락)
- 구내용 계산기 월평균 합 57,763 ≠ 월마감 57,738 (계산기 자체도 「불일치」 표시)

### 6-2. 단가가 섞여 있어요 (확인 필요)
- AJ자료입력 H열·협력업체 미수금: **2,500원**
- ★출력★·관계사 전표: 5월부터 **2,400원**
- 요약및변환 J열(2,500)과 T열(2,400)이 같이 있음
- AJ 기준단가표(2022): 구내용 **46원**, 수송용 **5,500원** ↔ 실제 8월 AJ 거래명세서: 구내용 **43원**, 수송용 **6,500원**

### 6-3. 구조가 깨지기 쉬움
- **행 순서 의존**: 월마감 행 순서 = AJ 거래명세서 시트 순서. 새 시공팀·협력사가 생기면 AJ가 "○○ 다음에 넣어 달라" 메일을 보내고 사람이 행을 끼워 넣음(2022-05 답변 메일). 한 줄만 밀려도 금액이 다른 곳에 붙어요.
- **이름 매칭**: VLOOKUP으로 업체명을 찾아서 철자가 다르면 0이나 #N/A가 돼요. 8월 청구 시트에 #N/A 6건(드림네트워크·에픽·제일퍼니처·인투스·매쉬스마트·스마일가구), #REF! 3건.
- **보정 수식**: INT 버림 뒤 남는 1~2장을 맞추는 보정(O열)이 위치마다 따로 붙어 있어, 구조를 모르면 고치기 어려워요.
- **사람 의존**: 담당자 퇴사로 바로 멈춤. 경유자(담당자) 시트도 2021~2022 기준 이름이 많아요.
- **보안**: 공유 폴더에 `공인인증서비밀번호.txt`가 평문으로 있어요. 옮기거나 지우는 걸 권해요(열어 보지 않았어요).

### 6-4. EDI·실물과의 관계
- 월마감은 **AJ 거래명세서 숫자를 그대로** 믿어요. 그 숫자는 EDI 재고에서 나와요.
- 앞서 찾은 **EDI 마이너스 재고(35곳, −24,107)**와 **시공팀 반납 미기록**이 그대로 청구에 들어가요. 시공팀은 반납이 안 잡히면 재고가 쌓여서 **우리가 더 청구하고, AJ에도 더 냄**.

## 7. PMS 자동화 설계

원칙: 사람이 하는 일은 **ERP 숫자 몇 개 입력**과 **최종 확인·전표 등록**만 남기기.

| 지금(엑셀) | PMS에서 | 자동/수동 |
|---|---|---|
| ① 거래명세서 400시트 → 계산기 → 값 붙여넣기 | `aj_stock_daily`(EDI 매일 재고)로 작업장별 **구내용 자동 계산** + AJ 거래명세서 엑셀을 올리면 작업장별 자동 대조(다르면 빨간 줄) | 자동 |
| ② 행 순서 맞추기 | 작업장마다 **청구 분류**(바로스센터·지방센터·시공팀·퍼시스공장·일룸협력사·시디즈공장·시디즈협력사·11A·15A·23E)를 DB에 한 번 지정. 새 작업장은 「분류 필요」로 표시 | 처음 1회 + 신규만 |
| ③ ERP 매출 비율 | 화면에 **9칸**(퍼시스·일룸·시디즈 × 경인내수·지방내수·해외) + 시디즈 재고금액 1칸 입력, 또는 ERP 자료변환 엑셀 올리기 | 수동(ERP 숫자만) |
| ④ 11A 출고 비율 | `aj_move`에서 11A 출고를 일룸·시디즈로 자동 집계 | 자동 |
| ⑤ 안분·보정 | 4장 규칙을 그대로 코드로(INT·보정 포함) → 엑셀과 같은 결과 나오는지 8월로 검증 | 자동 |
| ⑥ 출력·전월 대비 | ★출력★과 같은 화면 + 엑셀 내려받기 + 전월 대비 증감 | 자동 |
| ⑦ 전표 | 전표 줄(계정·거래처번호·코스트센터·적요·금액) 자동 생성 → **ERP 등록용 엑셀** | 자동 생성 → 사람이 ERP 등록 |
| ⑧ AJ 비용 검증 | 구내용×43 + 수송용×6,500 + 운반비로 AJ 청구 예상액 계산 → AJ 거래명세서와 대조, 마진 표시 | 자동 |
| ⑨ 마감 잠금 | 마감 확정 시 스냅샷 저장(이미 있음) — 뒤에 EDI가 바뀌면 "마감 후 변경" 경고 | 자동 |

> ERP·EP 화면은 사내 정책상 자동 조회·조작을 하지 않아요. ERP 숫자는 사람이 조회해서 PMS에 입력(또는 ERP에서 내려받은 엑셀을 올리기)하는 방식이에요.

**진행 순서 제안**
1. 8월 마감을 PMS로 **똑같이 재현**(엑셀과 원 단위까지 같은지) — 수식 오류 31장 차이는 따로 표시
2. 10월 마감(9/26~10/25)을 **엑셀과 PMS 병행** → 차이 원인 정리
3. 11월부터 PMS 기준, 엑셀은 검증용
4. 전표 엑셀 양식은 정훈님이 ERP 등록 화면 확인해 주시면 맞춤

## 8. 정훈님 확인이 필요한 것

1. **관계사 단가 2,400원(5월~)과 협력업체·내부 기준 2,500원** — 의도된 건가요? (관계사 인하 / 협력업체 유지)
2. **AJ 단가**: 실제 청구 구내용 43원·수송용 6,500원 — 지금 계약 기준이 맞나요? (2022 기준표는 46원·5,500원)
3. **9월·10월 마감** 진행 상태 — 폴더에 없어요. 이번에 막힌 게 10월 마감인가요?
