# AJ네트웍스 파렛트 구내용 산정 기준 확인 요청 (메일 초안)

**제목:** [레터스] 파렛트 임대 월마감 구내용 산정 기준 확인 요청

안녕하세요, 레터스 운송사업팀 현정훈입니다.

당사는 11월 마감부터 EDI 일별 재고 데이터를 기준으로 파렛트 월마감(구내용·월평균 산정 → 브랜드 청구·임차료 정산)을 자체 시스템으로 운영할 예정입니다.
준비 과정에서 귀사 거래명세서의 작업장별 구내용과 EDI 일별 재고 합계 간 차이가 확인되어, 산정 기준 확인을 요청드립니다.

## 1. 확인된 차이 (예시, 14C·18F 계정 P156063)
- 23E(P326529), 15A전용(P365851) 계정은 EDI와 거래명세서가 일치합니다.
- 일반 14C·18F 계정은 이동이 많은 센터를 중심으로 차이가 발생합니다.
  - 예) 양지물류센터: EDI 일별 재고 합 666,801 / 거래명세서 구내용 807,530
  - 예) 퍼시스안성: EDI 일별 재고에 마이너스 재고 발생
- 작업장별 상세 비교표를 첨부합니다. (PMS ‘마감 › ① 수량 대조’에서 내려받기)

## 2. 확인 요청 사항
1. **반영 기준일**: 구내용 산정 시 이동은 *이동(등록)일* 기준입니까, 받는 쪽 *입고확인(승인)일* 기준입니까?
2. **미승인·승인거부 이동**: 마감일(25일)까지 승인되지 않은 이동, 승인거부된 이동은 구내용에 어떻게 반영됩니까?
3. **마이너스 재고**: 일별 재고가 마이너스인 날은 0으로 처리합니까, 다른 방식으로 보정합니까?
4. **익월청구**: 청구재고 = 실재고 − 익월청구에서, 익월청구로 넘어가는 수량의 기준과 다음 달 반영 방식을 알려주십시오.
5. **재고조사 보정**: 실사 후 조정 수량이 EDI 이동으로 등록되지 않고 거래명세서에만 반영되는 경우가 있습니까?
6. **매각코드(작업장 448)**: 수량이 감소하는 사유와 마감 자료에서 제외되는 기준을 알려주십시오.
7. **일별 재고 원자료**: 거래명세서 구내용의 근거가 되는 작업장별 일별 재고(엑셀)를 매월 함께 받을 수 있습니까?

## 3. 요청
- 위 기준을 회신해 주시면 당사 시스템의 산정 방식을 귀사 기준에 맞추겠습니다.
- 가능하시면 10월분 양지물류센터 1곳에 대해 일별 구내용 내역을 공유 부탁드립니다. 차이 원인을 함께 맞춰 보고자 합니다.
